# Lever and LinkedIn Easy Apply

## Lever (`jobs.lever.co/{board}/{id}`)
Cost: **cheap**. Single-page form, form at `/apply`. Generally fully auto-fillable with `form_input`; custom questions are standard inputs.
- Board JSON: `https://api.lever.co/v0/postings/{board}?mode=json` — `createdAt` is epoch **milliseconds** (a number), not an ISO string.
- The job header shows department, level and pay type in one line — a cheap place to spot quota-carrying sales roles (department Revenue/Sales + OTE + sales IC level) before reading the full JD.
- Add dated notes here as you learn company-specific quirks.

## LinkedIn Easy Apply
Cost: **cheap**. Multi-step modal.
- Check which resume is selected — LinkedIn defaults to the last one you used. If it isn't this job's tailored PDF, upload the new one (stage-then-upload worked).
- Screening answers come from the Question Bank; check required fields before each Next.
- Read the full JD before judging fit: descriptions are collapsed by default — expand "See more" and read page text. Never judge by title and snippet.
- Search filters that matter: date posted (past week), salary floor, location; prefer Easy Apply.
